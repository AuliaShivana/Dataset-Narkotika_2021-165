               📜  Deskripsi Dataset
Dataset ini berisi 50 dokumen putusan pengadilan terkait perkara Pidana Khusus - Narkotika dan Psikotropika, yang diambil dari situs resmi Direktori Putusan Mahkamah Agung RI.
Dataset ini dibuat untuk keperluan pembelajaran mata kuliah Temu Kembali Informasi, Khususnya dalam topik preprocessing, Indexing, dan Retrieval dokumen hukum.

              🧠  Tujuan Penggunaan Dataset
Dataset ini dapat digunakan untuk:
- Pelatihan model information retrieval (TKI)
- Analisis teks hukum (text mining)
- Preprocessing dan Indexing dokumen hukum
- Studi kasus klasifikasi atau summarization putusan pengadilan

               ⚙️ Cara Akses Dataset
1. Unduh file `Narkotika.zip` dari folder `/Dataset`.
2. Ekstrak file tersebut ke komputer lokal.
3. Buka file `Overview.xlsx` untuk melihat ringkasan isi.
4. Gunakan dokumen untuk eksperimen TKI seperti tokenizing, stopword removal, stemming, indexing, dan searching.
